# Paola Juan · Artista plástica

Landing page para exhibir las acuarelas y la trayectoria de Paola Juan, profesora de Grabado y artista plástica.

- `index.html`: inicio, galería de obras con filtros por colección y visor ampliado, biografía, el taller y contacto.
- `styles.css`: estilos (responsive, pensado primero para celular).
- `script.js`: filtros de la galería, visor de obras y animaciones suaves al hacer scroll.
- `img/`: fotos de las obras en formato WebP.

Es un sitio estático: se puede publicar con GitHub Pages sin compilar nada.
Contacto: [@paolajuan_arte](https://www.instagram.com/paolajuan_arte/)
